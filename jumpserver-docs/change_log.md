v5.1.0
------------------------
2026年10月15日


- feat: KoKo 重构 TUI 终端交互，恢复纯文本连接模式，并新增资产树、搜索筛选、鼠标操作、多会话管理等功能，适用于通过 SSH 客户端直连 KoKo 的场景
- feat: Magnus 新增达梦数据库连接支持【企业版】
- feat: KoKo 新增对 Windows PowerShell WinRM 和达梦数据库 Web CLI 的支持，其中 WinRM 支持命令审计、ACL、会话录像及 AI 助手，可在 Luna Web 和桌面客户端中使用
- feat: Tinker 完成架构重构，基于 Windows 认证插件提供独立的 RDP 桌面，替代原有 RemoteApp 方案
- feat: Luna 工作台支持通过 DBX 连接数据库，并移除 DBeaver 远程应用，默认使用 DBX
- feat: 命令过滤规则支持 AI 辅助起草，并可通过小助手对话创建，同时优化命令过滤规则和命令组的配置体验
- feat: 资产登录 ACL 支持配置审批免审时长，审批通过后，同一用户使用同一账号连接同一资产时，在有效期内无需重复审批【企业版】
- feat: OAuth2 登录支持同步用户组，并可配置用户组属性映射及证书校验方式【企业版】
- feat: SAML2 远程元数据支持配置证书校验方式【企业版】
- feat: Zone 新增 CIDR 配置，可根据资产地址自动将资产归入对应 Zone
- feat: 标签页支持分组管理，分组信息可持久化保存并在下次使用时一键恢复，将标签页拖动至另一个标签页上即可自动创建分组
- feat: 新增个人凭据创建提醒和每日活动汇总，并记录凭据的最近使用时间，覆盖 Access Key、临时密码和连接令牌等凭据类型
- feat: 会话录像支持批量下载
- feat: 资产授权支持配置短期到期提醒
- feat: 工单审计支持按创建时间筛选和导出【企业版】
- feat: JDMC 新增主备管理、系统升级和补丁包管理功能


- perf: OpenBao 默认启用 HTTPS
- perf: 优化用户 MFA 配置，默认跟随系统设置，并对系统未启用的认证方式进行提示，系统强制启用 MFA 后，用户表单中的 MFA 默认开启且不可关闭
- perf: 优化 Chen Web 的 SQL 执行计划展示，新增概要视图和工具栏快捷入口
- perf: 优化工单导出内容，将审批流程、审批人、审批状态及关联资源转换为更易读的文本【企业版】
- perf: 优化 Lina 搜索交互，支持编辑搜索条件的 Value 值
- perf: 访问控制策略中的连接方式支持按资产进行选择【企业版】
- perf: LDAP 支持通过 distinguishedName 映射用户组
- perf: 账号模板明确标识跟随模板的字段，避免产生歧义
- perf: 站内信支持分页查看全部未读消息
- perf: 优化移动端连接按钮和紧凑布局的适配效果
- perf: 优化页面右下角的键盘及快捷键操作体验
- perf: Celery 日志统一在一个窗口中展示，并通过不同标签页进行切换
- perf: 优化 Ansible WinRM 启用 HTTPS 后的默认配置


- fix: 修复 KoKo 在部分旧款 CPU 环境中可能崩溃的问题
- fix: 修复创建作业时节点选择结果未保存的问题，并完善通过节点选择资产时的权限、命令过滤规则和脱敏规则检查
- fix: 修复 Redis SSL 校验配置未生效的问题
- fix: 修复 LDAP 连接超时配置未生效、LDAP HA 用户来源记录错误，以及 LDAP 用户列表缺少排序字段时发生异常的问题
- fix: 完善账号自动化中的 Jinja2 内容处理和用户名校验，防止非法采集账号进入后续自动化流程
- fix: 修复资产授权排除指定账号后，授权范围与详情列表显示不一致的问题
- fix: 修复 Web 连接未正确支持匿名用户的问题
- fix: 修复社区版 LDAP 定时同步开关未正常显示的问题
- fix: 修复 Web 连接场景中 AI 弹窗被页面遮挡的问题
- fix: 修复桌面客户端中 AI 面板自动展开的问题

v5.0.0
------------------------
2026年9月17日


- JumpServer 于 2014 年以开源堡垒机项目起步。十余年来持续稳步增长与不断迭代，在资产接入、访问控制与运维审计方面持续完善。2026 年 JumpServer v5.0 的发布标志着全新篇章的开启。
- JumpServer v5.0 推出焕新的原生客户端，为 SSH、RDP、Kubernetes、数据库与 RemoteApp 资产提供统一入口，并支持分屏视图、文件工作区、脚本库及 SFTP Server 连接。
- 新增 AI 辅助能力：命令推荐、实时操作风险告警与自动化审计报告，帮助团队更高效地工作、更轻松地审查运维操作。
- 升级 KoKo TUI：在 SSH 终端中可更便捷地查找资产、选择账号与协议，并在多个会话间切换。
